# Admin Panel — плавающие команды и нумпад поверх игры

## Как получить APK (без Android Studio)
1. Создай бесплатный репозиторий на github.com и залей туда все файлы этой папки (можно через «Upload files» в браузере с телефона).
2. Вкладка **Actions** → **Build APK** → дождись зелёной галочки (≈3–5 мин).
3. Внутри запуска, внизу, **Artifacts → AdminPanel-apk** → скачай, распакуй, установи APK.

## Первый запуск
1. «Показ поверх других окон» → включить.
2. «Спец. возможности» → **Admin Panel ввод** → включить.
3. «Запустить панель». Открой игру, нажми на поле чата (чтобы оно было в фокусе) и жми кнопки.

## Использование
- Кнопка команды дописывает её текст в поле (например `/report `).
- Нумпад: цифры дописываются, ⌫ стирает символ, ✔ отправляет (Android 11+).
- Панели таскаются за заголовок. Зелёный «+» открывает редактор команд.
- В редакторе: свои команды, порядок, размеры кнопок.
